PAYMENT LOGOS (official brand files)
Put the official logo files in this folder with these exact names (PNG or SVG, transparent background, roughly square or wide, max ~200px high is enough):

  pp.png   (or pp.svg)    -> PhonePe
  gp.png   (or gp.svg)    -> Google Pay
  pt.png   (or pt.svg)    -> Paytm
  upi.png  (or upi.svg)   -> BHIM / UPI

Download only from each company's official brand / press page and follow their brand rules.
If a file is missing, the app automatically shows a simple built-in logo instead.
